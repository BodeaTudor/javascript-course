CREATING AN OBJECT LITERAL:
To create an object the following syntax is used:
let variable_name = {};
The properties of an object are a set of key-value pairs (property_name: property_value).

'THIS' KEYWORD:
The 'this' keyword refers to the context in which the current code is being executed.
Its value can be different depending on where and how it is used.
In a browser, when used in the global context, 'this' usually refers to the window object.
When used inside a regular object method, 'this' usually refers to the object that called the method.

!!! IMPORTANT !!!
Arrow functions do NOT create their own 'this'.
Instead, they inherit 'this' from the surrounding context where they were defined.
Because of this, arrow functions are usually not a good choice for object methods when you want 'this' to refer to that object.

Example:
const user = {
    name: "Mario",

    regularFunction: function () {
        console.log(this.name);
    },

    arrowFunction: () => {
        console.log(this.name);
    }
};

user.regularFunction();
→ 'this' refers to user

user.arrowFunction();
→ 'this' does NOT refer to user
